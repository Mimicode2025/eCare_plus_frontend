# eCare_plus_frontend

Partie web (Frontend) de eCare+ pour le suivi des maladies chroniques (diabète et hypertension).

## Fonctionnalités

- Saisie et suivi des mesures de glycémie
- Saisie et suivi des mesures de tension artérielle
- Indicateurs automatiques (statut, moyenne, min, max)

## Lancer le projet

Ouvrir le fichier `/home/runner/work/eCare_plus_frontend/eCare_plus_frontend/index.html` dans un navigateur.

## Tests

npm test
